# 🧮 Calculadora Web

Calculadora web desenvolvida com **HTML, CSS e JavaScript** para praticar lógica de programação, eventos e manipulação do DOM.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Operações matemáticas básicas
- Interface simples e intuitiva
- Exibição dos valores na tela
- Manipulação do DOM com JavaScript

## 🌐 Projeto online

👉 [Acessar a calculadora](https://barbarasoaress.github.io/calculadora/)

## 📚 Objetivo do projeto

Este projeto foi desenvolvido durante meus estudos de JavaScript com o objetivo de praticar lógica de programação e desenvolvimento web.
